# sloneearly.github.io

Personal GIS portfolio for Slone Early, hosted on GitHub Pages.

## Files
- `index.html` - the whole site (one page)
- `style.css` - styles, with light and dark mode
- `.nojekyll` - tells GitHub Pages to serve the files as-is

## Publish
1. Create a public repo named `sloneearly.github.io` (it must match your GitHub username).
2. Upload `index.html`, `style.css`, `.nojekyll`, and this README to the repo root.
3. In the repo, go to Settings > Pages and set the source to the `main` branch, root folder.
4. The site will be live at https://sloneearly.github.io within a few minutes.

## Adding images later
Put image files in an `images/` folder and reference them like `<img src="images/peafowl-map.png" alt="...">`.
