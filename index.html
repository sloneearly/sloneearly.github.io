New World Screwworm Transmission Pathways

GEOG 476 GIS Practicum capstone · client brief from USDA / NGA Tearline

Our class is building an intelligence estimate on whether cattle movement from Guatemala through southern Mexico could carry New World Screwworm into South Texas. I am Team Lead for Team A, so I keep each member's component connected and set up regular cross-team red-teaming with Team B.

My own component is a data reliability check. It flags problem records in the detection data and shows where U.S. (APHIS) and Mexican (SENASICA) sources disagree. It runs three tests:

  • Unit consistency across the reporting sources
  • Coordinate plausibility for records that have real coordinates, using a projected CRS for distance checks
  • Source agreement between APHIS and SENASICA counts

Surprising records go back to their owners instead of being silently "fixed." The check does not claim the data is accurate. It shows where it should not be trusted yet.

Peafowl Movement, Home Range, and Interaction Analysis

Client work for a Texas A&M professor's grant proposal

I analyzed GPS telemetry data to build movement paths, home range estimates (MCP and KDE), and spatial proximity metrics in ArcGIS Pro. I also designed a workflow that finds encounters between birds that are close in both space and time. ArcGIS could not handle the timestamps well, so I wrote Python preprocessing in Jupyter to clean them first.

I finished with client-facing documentation so non-GIS users can rerun, change, and extend the analysis on their own.

INTA Exam Map

Department of Political Science, Texas A&M

I built a web map used to give a graduate-level exam. It needed to show and label only a set list of countries, in a set order. I cleaned the country names in the exam table to match the World Countries Generalized layer (for example, "Czechia" vs. "Czech Republic"), joined the two, and used a definition query to keep only matched countries.

Because joins do not carry over when publishing web maps, I exported the result as a new feature class with an ordering field so the labels stay in the right sequence in ArcGIS Online.

Vending Machine Beverage Availability on the East Quad

GEOG 352 (GNSS in the Geosciences) team project

Our team mapped every vending machine within about 700 to 800 feet of the Eller Oceanography and Meteorology Building. Over three days we collected point locations in Esri Field Maps and logged drink stock in Google Sheets, then averaged availability across days.

Langford Architecture Building (A) had the best variety and stock. The Computing Services Annex was the closest option to Eller. The Commons Dining Hall was the most often empty. We also reported our limits: indoor GPS error and sampling bias where several machines sat close together.
